# TacReports: project memory

## The idea (owner, 2026-10-03)
An Android app for report templates. Owner's words: "allow in short cuts to set up reports templates".

Working reading, still to confirm with the owner:
- The user builds their own report templates (fields, fixed text).
- A report is started from a template in a tap or two (e.g. Android home-screen shortcuts),
  filled in and sent.

## Open questions
1. Is "short cuts" home-screen shortcuts, or quickly assembling templates from ready blocks
   (time, grid position, free text)?
2. Which reports / formats should ship as examples?
3. How is a finished report sent: share to a messenger, copy as text, or via SimpleGrid's team relay?
